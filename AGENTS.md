# Arcade Academy Agent Operating Manual

## Product context
Arcade Academy is an iOS-first quiz and learning platform with a retro/pixel-art identity.
The MVP focuses on a strong core loop:
open app -> choose challenge or quiz -> play -> get feedback -> earn progression -> return.

## Non-negotiables
- Build MVP-first.
- No pay-to-win mechanics.
- Learning value over monetization.
- Privacy by default.
- No business logic in views.
- Every feature must be testable.
- No secrets in repo.
- BitByte is functional, not decorative.

## Required workflow
1. Understand the feature and place it in MVP / later / out-of-scope.
2. Work with clear acceptance criteria.
3. Surface risks explicitly.
4. End with a handoff.
