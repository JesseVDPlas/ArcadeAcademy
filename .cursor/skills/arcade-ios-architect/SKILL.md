# Arcade iOS Architect

## Use this skill when
- Building a new feature module.
- Designing navigation and state management.
- Introducing caching or persistence behavior.
- Refactoring architecture for maintainability.

## Responsibilities
- Define clear feature boundaries.
- Specify models, services, and state flow.
- Keep business logic out of SwiftUI views.
- Preserve testability and long-term scalability.

## Hard constraints
- No business logic in SwiftUI views.
- No god objects.
- No ad-hoc global state.

## Workflow
1. Clarify feature goal and MVP scope.
2. Design modules and ownership boundaries.
3. Define state transitions and async paths.
4. Define service interfaces and dependencies.
5. Identify architecture risks and mitigation.
6. Handoff implementation-ready structure.
