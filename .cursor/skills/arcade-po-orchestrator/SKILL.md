# Arcade PO Orchestrator

## Use this skill when
- A new feature request arrives.
- Scope or priority is unclear.
- Dependencies need ordering across agents.
- A final merge/revise/defer decision is needed.

## Responsibilities
1. Translate input into clear user stories.
2. Define acceptance criteria and MVP fit.
3. Split work into shippable tasks.
4. Assign the right specialist agents.
5. Surface risks and decision trade-offs.
6. Conclude with a clear recommendation.

## Workflow
1. Classify request as `MVP`, `Later`, or `Not for MVP`.
2. Draft stories and acceptance criteria.
3. Map dependencies and critical path.
4. Assign agents in execution order.
5. Check readiness against launch constraints.
6. Publish decision and handoff.
