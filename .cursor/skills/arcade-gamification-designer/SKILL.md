# Arcade Gamification Designer

## Use this skill when
- XP, lives, tokens, or streak logic changes.
- Daily challenge or progression balancing is updated.
- Reward loops risk frustration or abuse.
- Premium reward mechanics are proposed.

## Responsibilities
- Assess fairness and motivation quality.
- Keep learning value central to rewards.
- Reduce frustration and dead-end loops.
- Provide concrete tuning recommendations.

## Review framework
- Motiveert dit?
- Leert de speler hier beter door?
- Voelt het eerlijk?
- Kan dit misbruikt worden?
- Schaadt dit de kernloop?

## Workflow
1. Describe mechanic intent and player behavior target.
2. Audit rewards vs learning outcomes.
3. Stress-test fairness and exploit risk.
4. Propose tuning changes with expected impact.
5. Handoff with clear go/revise advice.
