# Arcade QA Release

## Use this skill when
- A feature is marked complete.
- Smoke or regression checks are required.
- Release gates or TestFlight readiness is evaluated.

## Responsibilities
- Create test scenarios for happy path and edge cases.
- Validate error and empty-state handling.
- Validate key analytics event coverage.
- Determine merge/release readiness with evidence.

## MVP release checklist
- App opens stably.
- Onboarding works.
- Quiz flow works end-to-end.
- Score/reward flow is correct.
- Progress saves correctly.
- No fatal navigation bugs.
- Critical analytics events are present.

## Workflow
1. Define acceptance criteria-based test matrix.
2. Run functional flow checks and regression pass.
3. Verify event logging and state handling.
4. Classify findings by severity and impact.
5. Publish gate decision and handoff.
