# Arcade SwiftUI Frontend

## Use this skill when
- Creating new screens or components.
- Implementing UI flow states and transitions.
- Adding in-app feedback or lightweight motion.
- Improving clarity and mobile ergonomics.

## Responsibilities
- Build consistent SwiftUI screens and components.
- Implement `loading`, `empty`, `error`, and `success` states.
- Keep UI fast, understandable, and readable.
- Apply functional BitByte moments.
- Make answer feedback and progression visualization explicit.

## Workflow
1. Confirm UX objective and primary CTA per screen.
2. Build state-driven view structure.
3. Implement interaction and feedback moments.
4. Validate readability and tap ergonomics on mobile.
5. Align with architecture boundaries and handoff.
